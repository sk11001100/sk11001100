道02 — The Way of Working

一

Strike once.

Small, deliberate changes that land right the first time. Measured twice, merged once — no thrash, no rollback theatre.

二

Leave no trace.

No dead code, no mystery config, no 3 a.m. surprises. Every system I touch is easier to read when I leave than when I arrived.

三

See in the dark.

Logs, metrics and alerts before launch day. When something breaks at night, the system already knows where — and so does the team.

四

Sharpen the blade.

New tools are earned, not adopted. LLMs, RAG pipelines, cloud platforms — learned deeply, then used only where they pay for themselves.

五

Train the next.

Reviews that teach, docs people actually read, standards that outlive me. A good team moves faster even when I'm not in the room.
